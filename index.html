  • Hipertexto. Un sitio web estático bilingüe dedicado a cerrar la brecha entre la inteligencia artificial y natural a través de comunicación científica, educación ambiental y resiliencia comunitaria. Incluye guías exhaustivas sobre prácticas sostenibles, aprendizaje basado en desafíos y documentación de proyectos estructurada con alojamiento en GitHub Pages.

  • Computo distribuido (Demo de Wordpress). Plataforma de gestión de infraestructura de producción que orquesta 7 servicios containerizados en Google Cloud. Implementé un sistema completo de proxy inverso con terminación TLS, resolución DNS, acceso VPN seguro, monitoreo de métricas y análisis web para 3+ dominios administrados.

  • Análisis de Estilos Musicales Utilizando el Algoritmo Random Forest. Coautor de documento de investigación presentando un método autónomo para analizar estilos musicales utilizando el algoritmo de bosques aleatorios combinado con Modelos Ocultos de Markov y Transformada Discreta de Wavelet. El enfoque extrae características relacionadas con la frecuencia de piezas musicales para clasificar y generar melodías que se ajusten a estilos musicales específicos, con aplicaciones en modelos computacionales de diseño y creatividad computacional.
